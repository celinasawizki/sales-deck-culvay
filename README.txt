CULVAY SALES DECK
Open index.html in a modern browser. Use arrow keys, space, or the bottom navigation. On phones, scroll through each slide.

For the most consistent download behavior, serve this folder locally:
python3 -m http.server 8766 --bind 127.0.0.1
Then open http://127.0.0.1:8766

With a direct file open, the worksheet may open in a new tab rather than download. Save it from the PDF viewer.

Send Culvay-Sales-Deck.pdf together with Culvay-Placement-Review.pdf. The PDF shows example calculator values; use the HTML deck for live calculations. PDF calls to action use email rather than local file links.

Edit copy in index.html, styles in deck.css, interactions in deck.js, and the printable worksheet in placement-review.html. REVIEW.txt explains the changes and the remaining evidence and offer decisions.

No installation is required to view the deck. No data is submitted by the calculator. Mail links open an email draft; the user chooses whether to send it.
